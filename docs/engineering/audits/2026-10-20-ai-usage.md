## Operational limits and review status

Apply migration017 through normal operator migration process before running the updated API. No historical tokens can be recovered. Input tokens remain NULL for these SDK image/video responses because providers do not expose that counter. Latency measures provider request time; video completed_at is the terminal observation time, duration_seconds is reported media duration. Polls and cancellation HTTP operations are lifecycle updates rather than billable-generation attempt rows.

A crash or failed final write after image generation can leave an attempt at started with unknown usage; no automatic paid retry is introduced. Video successful submissions retain task IDs and unique started-row recovery handles a lost final write on subsequent polling. Completion persistence failures emit only attempt/job identifiers and preserve the provider result. Recovery cannot reconstruct usage if the provider never returns it. No usage listing/dashboard endpoint is added.
